  - Built an interactive Angular Single Page Application with guarded routes, token interceptors, dynamic property search, filters, and booking management.
- **Key Highlights / Bullet Points for CV:**
  - Architected a distributed property rental system decomposing services using Domain-Driven Design (DDD) with Spring Boot and PostgreSQL.
  - Secured the entire ecosystem using **Keycloak OAuth2 / OpenID Connect**, integrating JWT token verification across API gateways and Angular frontend.
  - Implemented dynamic **Service Discovery** and **API Gateway** routing to achieve high availability and decoupled communication between microservices.
  - Built an Angular SPA consuming secured REST APIs, utilizing HTTP interceptors for automatic token refresh and role-based route protection.
